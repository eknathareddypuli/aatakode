# Contributing

AataKode is free for everyone, and missions are the heart of it.

## Add a mission
1. Copy an existing file in `missions/debug-the-outage/`.
2. Follow `docs/MISSION_FORMAT.md`.
3. Make sure the three hints get a stuck learner to the answer.
4. Open a pull request with the mission and a one-line note on what it teaches.

## Translate
Add translated `story`, `goal` and `hints` in a `translations/<lang>/` copy of the mission. Telugu, Hindi and Tamil are first.

## Principles
- No lesson behind a paywall.
- Original content only. Do not copy lessons from other platforms.
- Be kind: hints should help, not shame.
