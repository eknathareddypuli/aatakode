# Roadmap

## Phase 1: Prototype (weeks 1–3)
- [x] Single-page app shell: map, lesson view, editor, output panel
- [x] Mission loader (reads JSON from `missions/`)
- [x] In-browser grader (tests run client-side)
- [x] Simulated terminal for shell missions
- [x] XP and progress in localStorage, export/import
- [x] "Debug the Outage" region (20 missions) and 6 Mystery Cases

## Phase 2: Alpha (weeks 4–8)
- [x] Step-through visualizer (variables, loops, call stack)
- [x] Streaks with freeze days, badges, skill-tree map
- [ ] Verifiable certificates
- [x] v2: SQL and Git tracks, Career Boost, Arena (golf, pair, speed, dungeon), placement quiz, Seeds, village building, companions, sound, haptics, day and night
- [x] Mobile layout, accessibility pass (keyboard, contrast, reduced motion)
- [x] 12 Python regions (137 missions) built and verified
- [ ] Test with 10–20 real learners and tune difficulty

## Phase 3: Beta (months 3–4)
- [ ] Optional accounts and cloud sync
- [ ] Weekly opt-in leagues, co-op bug raids
- [ ] Pre-written hints plus metered AI hints
- [ ] Contribution flow for missions via pull request

## Phase 4: Launch (months 5–6)
- [ ] Premium tier (sync, AI tutor, mentor review, classrooms)
- [ ] First translation (Telugu), then Hindi and Tamil
- [ ] Public launch

## Guardrails
- No lesson is ever locked behind payment.
- Rewards track demonstrated skill, not time spent.
- Anything public (certificates, leaderboards) is verified server-side.

- Also built: Daily Quest, stars, story map, outfits, certificate cards, class goal.
- Built so far: 20 missions (Python Quest + 4 outages), teacher dashboard (offline), Outage of the Week, solution comparison, block view, Telugu UI.

## v4 (built)
Bot Arena, Clash of Code, read-the-code, Explain panel, fair motivation design, calm mode, install guide, health dashboard, printables.

## v5 (built)
Goal chooser, mastery map, Game Workshop and Micro-Jobs tracks, Maze Dash, story bosses, parrot growth, misconception detector.

## After v4
- A friends leaderboard that needs no account (shared files), and more Arena games beyond Seed Grab.
- Native-speaker review of translations.

## After v3
- Native-speaker review of festival greetings and the new nav labels (they fall back to English).
- Real Go in the browser (WASM toolchain) to replace static grading.
- More projects and a Rust track.
